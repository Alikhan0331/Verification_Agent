# Выписка по карте за период

Контрольный документ без заложенных дефектов: требования пронумерованы, измеримы, согласованы между собой.

## Общие сведения

| Поле | Значение |
| :--- | :--- |
| **Наименование задачи** | Формирование выписки по карте за выбранный период |
| **Версия / дата** | 1.0 / 05.11.2026 |
| **Продукт** | Мобильный банк, карты |
| **Тип работы** | Новый функционал |
| **Влияние на ИС** | Мобильный банк, сервис выписок, хранилище операций |
| **Согласовано** | Владелец продукта — Иванов А. (05.11.2026); архитектор — Петров Б. (06.11.2026); ИБ — Сидорова В. (06.11.2026) |

## Термины

* **Держатель** — физическое лицо, на имя которого выпущена карта.
* **Период выписки** — интервал дат от даты начала до даты окончания включительно, по времени Астаны (UTC+5).
* **Операция** — проведённая по карте транзакция со статусом «исполнена»; блокировки и отклонённые операции не входят в выписку.

## Цели

* **G-1.** Дать держателю возможность самостоятельно получить выписку по своей карте за выбранный период в формате PDF.

## Функциональные требования

* **FR-1.** Держатель выбирает карту, дату начала и дату окончания периода. Период не может превышать 366 календарных дней, дата окончания не может быть позже текущей даты.
* **FR-2.** Если период выбран с нарушением правил FR-1, приложение не отправляет запрос и показывает под полем даты сообщение: «Период не может превышать 366 дней и заканчиваться в будущем».
* **FR-3.** Выписка содержит операции периода в порядке убывания даты исполнения и включает для каждой операции: дату и время исполнения, сумму в валюте карты, тип операции и название контрагента.
* **FR-4.** Выписка содержит остаток по карте на начало и на конец периода в валюте карты.
* **FR-5.** Если за период нет ни одной операции, выписка содержит остатки и текст «Операций за период нет».
* **FR-6.** Выписка формируется только для карт, принадлежащих авторизованному держателю. При запросе чужой карты сервис возвращает ответ 404, как и для несуществующей карты.
* **FR-7.** Готовую выписку держатель может скачать в приложении в течение 24 часов с момента формирования; после этого файл удаляется, а запрос на скачивание возвращает ответ 410.

## Нефункциональные требования

* **NFR-1.** Для 95% запросов на выписку за период до 31 дня включительно файл формируется не более чем за 10 секунд при нагрузке до 50 запросов в секунду.
* **NFR-2.** Сервис выписок доступен не менее 99,5% времени в календарный месяц, измеряется по ответам на проверку состояния каждую минуту.
* **NFR-3.** Файл выписки хранится в зашифрованном виде (AES-256), доступ к нему проверяется по идентификатору держателя при каждом скачивании.
* **NFR-4.** Каждый запрос и скачивание выписки записываются в журнал аудита: идентификатор держателя, идентификатор карты, период, время, результат. Журнал хранится 5 лет.

## Требования к данным

* **DR-1.** Сумма операции хранится и передаётся в тиынах как целое число 64 бит; в выписке отображается в тенге с двумя знаками после запятой.
* **DR-2.** Время исполнения операции хранится в UTC и отображается в выписке по времени Астаны.

## Требования к интеграции

* **IR-1.** Приложение запрашивает выписку методом `POST /statements` с телом `{"cardId": string, "from": "YYYY-MM-DD", "to": "YYYY-MM-DD"}` и получает `202 Accepted` с идентификатором выписки.
* **IR-2.** Приложение получает готовую выписку методом `GET /statements/{id}`: `200` — файл PDF, `202` — выписка ещё формируется, `404` — выписка не найдена или принадлежит другому держателю, `410` — срок хранения истёк.
* **IR-3.** Ошибки валидации запроса возвращаются как `400` с полем `message`; отсутствие авторизации — `401`; внутренняя ошибка — `500`.

## Откат

* **RB-1.** Функция включается флагом `statements.enabled`. При значении `false` пункт меню «Выписка» скрывается, а методы возвращают `404`; ранее сформированные файлы не удаляются.

## Критерии приёмки

| ID | Покрывает | Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- | :--- | :--- |
| AC-1 | FR-1, FR-2 | Держатель выбирает период в 367 дней | Нажать «Сформировать» | Запрос не отправляется, под полем даты показано сообщение из FR-2 |
| AC-2 | FR-1 | Период ровно 366 дней, дата окончания — сегодня | Нажать «Сформировать» | Запрос отправлен, получен ответ 202 |
| AC-3 | FR-3, FR-4 | В периоде 3 операции | Скачать выписку | Операции в порядке убывания даты, указаны остатки на начало и конец |
| AC-4 | FR-5 | В периоде нет операций | Скачать выписку | В выписке остатки и текст «Операций за период нет» |
| AC-5 | FR-6, IR-2 | Карта принадлежит другому держателю | Запросить выписку | Ответ 404 |
| AC-6 | FR-7, IR-2 | С момента формирования прошло 24 часа 1 минута | Скачать выписку | Ответ 410 |
| AC-7 | DR-1 | Операция на 1 234 567 тиын | Скачать выписку | В выписке указано 12 345,67 ₸ |
| AC-8 | RB-1 | Флаг `statements.enabled` выключен | Открыть меню карты | Пункта «Выписка» нет, методы возвращают 404 |
| AC-9 | NFR-4 | Выписка запрошена и скачана | Проверить журнал аудита | Две записи с полями из NFR-4 |
