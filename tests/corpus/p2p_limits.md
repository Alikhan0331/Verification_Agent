# Лимиты на переводы между картами (P2P)

Учебный документ для проверки агента. Содержит намеренно заложенные дефекты.

## Общие сведения

| Поле | Значение |
| :--- | :--- |
| **Наименование задачи** | Лимиты на переводы между картами |
| **Версия / дата** | 1.1 / 03.11.2026 |
| **Продукт** | Мобильный банк, переводы |
| **Тип работы** | Изменение существующего функционала |

## Цели
Снизить риск мошенничества за счёт ограничения суммы переводов между картами.

## Функциональные требования

* **FR-1.** Суточный лимит переводов с карты составляет 500 000 ₸ для всех клиентов.
* **FR-2.** Для клиентов, не прошедших полную идентификацию, суточный лимит составляет 100 000 ₸.
* **FR-3.** Суточный лимит считается за сутки, предшествующие операции.
* **FR-4.** Комиссия за перевод составляет 0,5% от суммы перевода и округляется.
* **FR-5.** При превышении лимита перевод отклоняется, клиенту показывается сообщение.
* **FR-6.** Переводы на карты, выпущенные в иностранной валюте, выполняются по курсу конвертации.
* **FR-7.** Месячный лимит переводов с карты составляет 3 000 000 ₸.
* **FR-8.** Предельная сумма переводов за календарный месяц — 2 500 000 ₸.
* **FR-9.** Для хранения счётчиков использовать Redis с TTL 24 часа.

## Нефункциональные требования

* **NFR-1.** Система должна выдерживать высокую нагрузку в часы пик.
* **NFR-2.** Проверка лимита не должна заметно задерживать перевод.

## Требования к интеграции

Метод `POST /p2p/check` проверяет возможность перевода.

* Статус 402. Превышен суточный лимит.
* Статус 200. Перевод разрешён.

Логика метода: при превышении суточного лимита вернуть статус 429.

## Критерии приёмки

| Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| Израсходовано за сутки 450 000 ₸, лимит 500 000 ₸ | Перевод 60 000 ₸ | Перевод выполнен |
| Клиент без полной идентификации, израсходовано 0 ₸ | Перевод 100 000 ₸ | Перевод выполнен |
| Перевод на сумму 1 000 ₸ | Проверить комиссию | Комиссия 5 ₸ |
